- **Takeoff occurs after the angular size reaches a fixed threshold (independent of how fast the looming is)** — **The default 2.5 mm ball cannot reveal this rule** (coefficient of variation 38.5%)—because then 54° corresponds to a distance of only **4.9 mm**, while the contact distance is 3.9 mm, so in that scene the paper's threshold amounts to "already in its face". Only with an 8 mm stimulus (54° corresponds to 15.7 mm) does the rule appear. One built-in bias must also be stated: in the Ache 2019 encoding LPLC2 is a Gaussian of angular size (peak 42°), so "taking off at a fixed angular size" partly comes from the encoding; the non-trivial part is **how speed-independent the threshold is, to within 2.3%**. Sweeping lc4Slope (0→0.5) does not affect the threshold at all, so it is not due to the angular-velocity term; raising the giant fibre threshold to 220 Hz pushes the angle to 22°, but takeoffs drop from 62 to 4, and any higher there is no takeoff at all (notebook §43)
- **The giant fibre does not respond to looming stimuli (escape uses a different descending pathway)** — **What we measured is not the paper's exact claim**: the paper uses in vivo recordings + real visual stimuli, whereas we inject Poisson firing directly into LC4/LPLC2, skipping all visual processing from retina to lobula. So the conclusion only reaches "under this wiring diagram + LIF parameters, LC4/LPLC2 population firing drives the giant fibre strongly and specifically"—siding with Ache 2019 and contrary to the in vivo results of Fotowat 2009. The criterion was written after looking at the reference table (labelled honestly), but with a 44 vs 4 Hz gap the conclusion is the same however the criterion is set. Read-only recomputation, zero new simulations. **This directly conflicts with our game's design**: the game triggers takeoff when the giant fibre (DNp01) crosses threshold. But it is not simply right or wrong—the literature itself is in tension: Fotowat 2009 found the giant fibre does not fire to looming (all 7 white-eyed flies), and Dα7 mutants still escape with 81–89% probability; while Ache et al. 2019 (the paper our encoding is based on) is precisely about how LC4/LPLC2 encode looming into the giant fibre. von Reyn et al. 2014 explains this as **two escape modes**: the giant fibre handles the "short mode" (trading stability for speed), while the slow looming Fotowat used (l/|v| 10–80 ms) evokes the "long mode" with wing raising first, which does not need the giant fibre. **Our model has no distinction between the two modes**, nor any wing raising, so the half that says "the long mode doesn't need the giant fibre" still cannot be tested—testing it would first require building long/short modes and wing raising into the model (notebook §43 + §45)

- **Odour valence experiment (authors' README self-reports 6/6)** — **3 of the criteria are 'real vs shuffled connectome', and the shuffled arm's readout does not fire at all** (readout mean 0.0 Hz, 0 active, in all 24 checkpoints) — the control is simply dead, so any non-zero effect passes, and such criteria are empty. The median turn_drive in every real condition is **−0.10**, dominated by a common bias (notebook §10.5 + §42)
- **Sign of turn_drive (docs say positive turns right, the code turns left)** — Moreover, left LPLC2 injection turns the fly **towards the stimulated side**, the opposite of the "contralateral escape" the authors report. Three caveats: ① absolute lateral displacement cannot reveal direction (the no-injection control also drifts −15.56 mm, a gait bias); ② shuffling changes locomotion as a whole (baseline drift after shuffling is only −3.47 mm), so only the left–right difference can be compared cleanly; ③ n=3 seeds (notebook §34)

- **Once placed inside a search, how well does it play (the user's goal: playing strength)** — Criterion A (intuition vs the old teacher ≥ 50%) **does not hold** (45.0%); A2 (thinking 6 moves ahead vs the teacher searching 4 ≥ 50%) holds (77.5%). **Playing strength comes mainly from search depth, not from the fly**: look-ahead is done by alpha-beta, and the search knows only the rules (five in a row, must block five, forbidden moves) and contains no shape scores; each extra ply multiplies the node count by about ×2.26 (`depth_timing.json`: depth 14 takes 10.13 seconds). 40 games per group (20 for the depth-8 teacher), standard deviation about 8 percentage points. Table precision is also worth playing strength (adding noise to the teacher's table down to R² 0.85 drops the same-depth win rate from 45.0% to 20.0%), but this brain's reliable precision ceiling is R² ≈ 0.85–0.88 (notebook §46.6)

A view = another random assignment table that hands the 24 channels to another set of input neurons; adding dimensions by splitting into time bins is a dead end (in-sample R² 0.976, across seeds 0.386). - **Can multi-step reasoning be trained into the readout (the user's requirement: reasoning must come from a trained model, not from a search run live during play)** — The pre-registered criterion "model trained on 8-move labels vs model trained on 1-move labels, 200-game win rate ≥ 55%" **does not hold** (36.0%, draws counted as non-wins). At the user's request the page defaults to pure model inference (reasoning steps = swapping the readout); alpha-beta is kept only as external search, off by default and labelled "algorithm, not fly"; handing the same table to a search thinking 6 moves ahead gives 31–9 against the teacher searching 4 — the gap comes entirely from the search (notebook §46.9)

- **Ecobox: distilling the 15,055-neuron real brain into a response surface (27 inputs → 12 readouts) so that the evolution of 32 flies can run** — The response surface has no memory (the real brain keeps state between decisions); it gives the mean firing rate over a 300 ms window, with single-trial noise added back as Poisson.
