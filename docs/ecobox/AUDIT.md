## 3. 七种动作

| 动作 | 由谁决定 | 状态 |
|---|---|---|
| 转向 | 连接组：转向神经元 DNa01/02 的左右差 → 左右步幅差 → 六条腿 | **接上了**（逼近、正面逼近、热能定向；气味 B、触碰只会朝固定一侧转；食物 / 水的气味不会） |
| 走 | 没有「开始走」的神经元接到身体上：行走是默认状态（这个模型没有自发活动）。前进神经元 oDN1 / BDN2 在回路里、会被热和气味 B 驱动，但**没有映射到步速** | **没接上**（走是默认的） |
| 停 | 没有「停」的神经元；只有进食 / 梳理时才停 | **没接上** |
| 进食 / 喝水 | 连接组：糖 / 水味觉 → MN9 伸喙；身体状态调感受器灵敏度（饿了更敏感） | **接上了**（但只在踩到食物 / 水之后） |
| 起飞 | 连接组：巨纤维 ≥ 90 Hz → 起飞（逃逸反射） | **接上了**（反射）；「主动起飞」没有神经通路 |
| 降落 | 手写：逃逸片段播完就落地 | **没接上** |

## 4. 飞行链路

- 起飞：连接组：巨纤维平滑发放 ≥ 90 Hz → 起飞（反射，已实测）
- 空中：没有接：起飞后播放一段录好的真实逃逸轨迹（flybody 控制器在物理里复飞），大脑不参与，不能转向、不能选落点（2 段录像：evasion_067_policy None s、evasion_044_policy None s）
- 降落：手写：片段末尾插值回行走姿态
- **结论：「起不起飞」可以是一个决策量；「怎么飞」现在学不了。** 所以 M2 里「飞行作为可学技能」锁着；先天的逃逸起跳保留（它是连接组自带的反射，不是学来的）。M3 把「飞行倾向」（起飞阈值的高低 + 无威胁时主动起飞的概率）作为**可遗传**的量放开——飞一次是一段不可操控的弹道，耗能高、受风影响、落点随缘，值不值得飞由环境决定。

## 5. 学习链路

| | 实测 |
|---|---|
| 蘑菇体的气味记忆会形成吗 | 是 |
| 只记配对过的那一种吗 | **否**（差一点，见 §48.3） |
| 记忆走得到运动输出吗 | **否** |
| 糖 / 苦 / 热 / 湿能靠真实接线叫起多巴胺神经元吗 | **否** |
| 页面引擎与 Python 学到的一致吗 | 是 |

**结论：连接组自己不会因为「吃到东西」而改变行为。** 要让它在生存压力下学出策略，必须在连接组之外加一层可塑的读出（PLAN.md 里的「可塑性层」），奖励信号由身体的内部状态自动产生。连接组仍然是固定的身体：它提供先天反射，也提供可塑性层能读到的全部放电。

## 6. 速度：为什么需要响应面

| | 实测 |
|---|---|
| 真脑每 5 ms 物理步（安静 / 闻着气味） | 2.23 ms / 4.22 ms |
| 一只果蝇 | 1.18 × 实时 —— 开不了时间加速 |
| 32 只同时 | 0.037 × 实时 —— 不可能 |

所以快进和群体必须用**从真脑采样出来的响应面**（同一接口，输入频率 → 各读出群的发放率），镜头里那一只可以随时切回真脑并排核对；页面上写明谁在跑什么、响应面的拟合优度是多少。
