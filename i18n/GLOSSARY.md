## Rules for translators

- Keep every placeholder exactly: `{0}`, `{1}`, …, and `{#}`.
- Keep every number, unit, Hz, mm, ms, %, ×, arrows (→), code identifiers (`CB0883`, `MN9`, `DNa01`, `LPLC2`, file names, function names, URLs), and neuron/cell-type names unchanged.
- Keep markdown markers (`**bold**`, backticks) and leading/trailing punctuation like `·`, `—`, `：` → `: `. Chinese full-width punctuation becomes English punctuation.
- UI labels stay short (button text is a word or two). Do not add explanations that are not in the Chinese.
- Chinese dates like `2026-09-19` stay as they are.
- If a string is purely a proper name or already mostly English (e.g. `DNa 转向`), translate only the Chinese part.
